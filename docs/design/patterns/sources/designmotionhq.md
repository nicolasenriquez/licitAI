# DesignMotionHQ

Source: `https://www.designmotionhq.com/patterns`

Catalog snapshot reviewed: **2026-08-28**. Patterns present at review time: **73**.

## Role

DesignMotionHQ is a secondary design reference. It is useful for discovering
interaction questions, failure modes, state completeness, and micro-interaction
considerations. It is not a repository specification.

## Not normative for

Do not use this source to override repository code, package contracts, Twenty
components, the Mercado Público feature contract, WCAG or WAI-ARIA guidance, or
the platform. It is not authoritative for exact pixel values, animation
durations, easing curves, radii, shadows, gradients, accessibility claims,
backend behavior, or definitions of “premium”.

## Safe consumption rule

Inspect the user problem and current implementation first. Search for an
existing Twenty primitive. Load the matching guide. Check applicability and
repository precedence. Use the external source only to inform a concise,
repository-specific interpretation.

Do not copy external articles into this repository. Keep attribution and the
original source URL in the relevant leaf.

## Review tiers

- Tier 1: product fundamentals and state completeness;
- Tier 2: contextual product patterns;
- Tier 3: interaction polish;
- Tier 4: optional aesthetics.
