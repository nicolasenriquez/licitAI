# Range Sliders

`UI-PAT-028` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

Approximate bounded range selection is easier to understand than direct entry.

## Do not apply when

Users need precise values and no precise input or value display is provided.

## Repository interpretation

Pair the slider with a clear value representation and keyboard operation. Use an
existing Twenty primitive.
