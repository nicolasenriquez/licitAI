# Form Validation Timing

`UI-PAT-031` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `REQUIRED`

## Use when

A field or form needs validation feedback during entry or submission.

## Do not apply when

Continuous validation interrupts normal typing or makes correction harder.

## Repository interpretation

Validate at meaningful boundaries, associate errors with fields, preserve input,
and make recovery clear. Do not use color as the only signal.
