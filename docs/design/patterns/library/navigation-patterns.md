# Navigation Patterns

`UI-PAT-044` · Primary guide: [Navigation](../navigation.md)

Posture: `REQUIRED_AS_CONTEXT`

## Use when

A change affects routes, shell navigation, tabs, or context restoration.

## Do not apply when

A new navigation model duplicates the existing Twenty shell or loses task state.

## Repository interpretation

Follow existing routing and package contracts. For Mercado Público, keep the
search-to-detail flow and existing side panel.
