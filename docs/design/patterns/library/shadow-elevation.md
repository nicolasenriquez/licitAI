# Shadow Elevation

`UI-PAT-061` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `CONTEXTUAL`

## Use when

Existing design-system tokens need subtle separation for a real layered surface.

## Do not apply when

Shadows are decorative, excessive, or used to manufacture a “premium” effect.

## Repository interpretation

Use existing Twenty shadow tokens and preserve light/dark parity. Do not create
page-local elevation recipes.
