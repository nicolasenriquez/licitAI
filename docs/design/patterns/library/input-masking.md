# Input Masking

`UI-PAT-027` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

A strict, well-understood format helps users enter a structured value.

## Do not apply when

Masking corrupts paste, caret position, raw values, localization, or assistive
technology behavior.

## Repository interpretation

Prefer understandable formatting and preserve the value contract. Test typing,
editing, paste, delete, validation, and recovery.
