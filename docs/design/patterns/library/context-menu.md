# Context Menu

`UI-PAT-008` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `CONTEXTUAL`

## Use when

Secondary expert actions are associated with a clear target and have visible
keyboard and touch equivalents.

## Do not apply when

The menu hides a primary action or is the only way to discover a critical
operation.

## Repository interpretation

Reuse Twenty menu primitives. Preserve target context, focus, escape behavior,
and action scope.
