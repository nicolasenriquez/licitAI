# Von Restorff Effect

`UI-PAT-071` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `HEURISTIC`

## Use when

One item has a real, user-relevant priority that needs emphasis.

## Do not apply when

Everything is emphasized or visual contrast manipulates users instead of
clarifying the task.

## Repository interpretation

Use sparingly with semantic tokens and text. Domain priority wins.
