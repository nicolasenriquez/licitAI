# Gradient Design

`UI-PAT-064` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `PROHIBITED_PRODUCT_UI`

## Use when

Only when working on a separate marketing register that explicitly permits the
treatment.

## Do not apply when

Working on Twenty product UI or Mercado Público.

## Repository interpretation

The current product design system prohibits gradients. Do not bypass tokens or
introduce decorative backgrounds.
