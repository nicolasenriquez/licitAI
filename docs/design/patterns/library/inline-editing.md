# Inline Editing

`UI-PAT-005` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

Inline editing reduces interruption and the field can support clear enter,
cancel, validation, pending, and rollback behavior.

## Do not apply when

Editing needs broad context, complex validation, or a separate workflow.

## Repository interpretation

Preserve layout, focus, keyboard behavior, and server truth. Reuse existing
Twenty field and mutation primitives.
