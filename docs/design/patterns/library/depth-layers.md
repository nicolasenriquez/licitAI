# Depth Layers

`UI-PAT-073` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `PROHIBITED_BY_DEFAULT`

## Use when

Only when existing component behavior needs a restrained, token-defined layer
relationship for comprehension.

## Do not apply when

Depth means parallax, glow, glassmorphism, excessive shadow, or decorative
separation in product UI.

## Repository interpretation

The restrained Twenty visual language wins. Do not add decorative depth to
Mercado Público.
