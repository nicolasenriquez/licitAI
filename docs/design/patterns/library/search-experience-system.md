# Search Experience System

`UI-PAT-012` · Primary guide: [Search and Filter Discovery](../search-filter-discovery.md)

Posture: `REQUIRED_WHEN_SEARCH_EXISTS`

## Use when

Users search a dataset or list to discover relevant records.

## Do not apply when

There is no meaningful searchable scope or the query would imply unsupported
backend behavior.

## Repository interpretation

Make scope, keyboard behavior, result feedback, no-result recovery, URL state,
and cursor reset explicit. Use domain labels, not raw field names.
