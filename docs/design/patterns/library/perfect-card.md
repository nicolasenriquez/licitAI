# Perfect Card

`UI-PAT-072` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `AVOID_AS_RULE`

## Use when

A card is already the correct repository component for a coherent content
group.

## Do not apply when

Cards are used to decorate or fragment dense records that need table scanning.

## Repository interpretation

Use existing Twenty card primitives and product density. Do not import an
external “premium card” recipe.
