# Loading States System

`UI-PAT-037` · Primary guide: [Feedback and Recovery](../feedback-and-recovery.md)

Posture: `REQUIRED`

## Use when

Content or an action has a lifecycle that users must understand.

## Do not apply when

A spinner replaces known structure or the UI suggests progress that is not
actually measured.

## Repository interpretation

Choose table-shaped skeleton, spinner, progress, or local pending from known
shape and progress. Preserve content context and announce meaningful status.
