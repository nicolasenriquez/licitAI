# Toast Notifications

`UI-PAT-039` · Primary guide: [Feedback and Recovery](../feedback-and-recovery.md)

Posture: `CONTEXTUAL`

## Use when

Short, non-blocking confirmation or failure feedback does not need to remain
visible.

## Do not apply when

The message contains required instructions, important records, or the only
recovery path.

## Repository interpretation

Use existing toast primitives, accessible status, useful duration, and a durable
alternative when the information matters.
