# Empty States

`UI-PAT-052` · Primary guide: [Feedback and Recovery](../feedback-and-recovery.md)

Posture: `REQUIRED`

## Use when

A list, table, search, or detail surface has no displayable records.

## Do not apply when

An empty message hides loading, failure, unavailable data, or a filtered result.

## Repository interpretation

Distinguish first-use, true empty, search-empty, filtered-empty, and unavailable
states. Use accurate domain copy and recovery.
