# Drag and Drop

`UI-PAT-009` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

Dragging directly represents a real domain operation such as ordering or
grouping.

## Do not apply when

Dragging is only decorative or no keyboard and non-drag alternative exists.

## Repository interpretation

Expose the resulting state, cancellation, failure, and keyboard alternative.
Do not make procurement decisions depend on pointer precision.
