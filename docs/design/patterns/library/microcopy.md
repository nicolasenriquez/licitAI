# Microcopy

`UI-PAT-054` · Primary guide: [Feedback and Recovery](../feedback-and-recovery.md)

Posture: `RECOMMENDED`

## Use when

Labels, errors, empty states, confirmations, and recovery actions need clearer
language.

## Do not apply when

Copy invents domain facts, exposes backend field names, or uses vague text that
does not help the user act.

## Repository interpretation

Use Spanish product labels where required, Lingui-compatible messages, accurate
procurement language, and approved unavailable-value wording.
