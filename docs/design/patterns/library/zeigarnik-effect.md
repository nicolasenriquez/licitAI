# Zeigarnik Effect

`UI-PAT-040` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `HEURISTIC`

## Use when

An actual incomplete workflow needs clear progress or a next step.

## Do not apply when

Artificial incompleteness or attention tricks would create pressure without
helping task completion.

## Repository interpretation

Use accurate state and copy. Do not manufacture progress or unfinished work.
