# Doherty Threshold

`UI-PAT-035` · Primary guide: [Feedback and Recovery](../feedback-and-recovery.md)

Posture: `HEURISTIC`

## Use when

Reviewing whether feedback and progress keep users oriented during a wait.

## Do not apply when

A remembered timing value would become a false SLA or a substitute for real
performance measurement.

## Repository interpretation

Use existing loading and progress patterns. Measure actual behavior before
choosing a change.
