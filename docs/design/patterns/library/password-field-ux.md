# Password Field UX

`UI-PAT-033` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

An authentication or credential workflow requires password entry.

## Do not apply when

The control invents identity-provider policy or makes password managers and
assistive technology unreliable.

## Repository interpretation

Follow the identity provider and existing authentication contract. Preserve
labels, autocomplete, visibility control, validation, and recovery.
