# Grid System

`UI-PAT-059` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `RECOMMENDED`

## Use when

Alignment and responsive composition help users scan and complete a task.

## Do not apply when

A fixed grid damages content width, density, narrow layouts, or existing
Twenty primitives.

## Repository interpretation

Use existing layout and spacing tokens. A 12-column grid is not mandatory.
