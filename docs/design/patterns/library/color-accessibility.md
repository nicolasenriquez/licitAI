# Color Accessibility

`UI-PAT-067` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `REQUIRED`

## Use when

Color communicates state, grouping, status, or emphasis.

## Do not apply when

Color is the only signal or a palette change breaks contrast or theme parity.

## Repository interpretation

Use semantic tokens and text, icons, structure, or patterns with color. Meet the
repository's WCAG AA baseline.
