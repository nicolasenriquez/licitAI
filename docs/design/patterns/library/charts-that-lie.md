# Charts That Lie

`UI-PAT-056` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `REQUIRED_WHEN_CHARTING`

## Use when

A chart communicates real data, comparisons, trends, or distributions.

## Do not apply when

The chart implies unsupported precision, uses misleading scales, or derives
universe metrics from a partial or paged response.

## Repository interpretation

Use truthful encodings, labels, units, empty/error states, and source scope.
Never invent Mercado Público metrics, scores, or recommendations.
