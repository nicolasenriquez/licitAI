# Date Pickers

`UI-PAT-025` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `RECOMMENDED`

## Use when

A date or date range is a real domain value and calendar selection improves
entry without replacing precise text input.

## Do not apply when

The format is ambiguous, keyboard entry is blocked, or a calendar adds no value.

## Repository interpretation

Reuse existing date primitives. Preserve locale, format clarity, keyboard
operation, validation, time-zone semantics, and responsive behavior.
