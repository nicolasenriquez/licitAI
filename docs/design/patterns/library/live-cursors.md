# Live Cursors

`UI-PAT-006` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `AVOID_BY_DEFAULT`

## Use when

Real-time collaboration is a confirmed product requirement and identity,
privacy, presence, and performance are defined.

## Do not apply when

The surface is a single-user CRM or procurement workflow without collaboration
semantics.

## Repository interpretation

Do not add collaboration decoration to Mercado Público. A visual effect cannot
stand in for a real presence contract.
