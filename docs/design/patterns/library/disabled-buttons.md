# Disabled Buttons

`UI-PAT-002` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

An action is truly unavailable and the reason can be communicated nearby.

## Do not apply when

The action is merely busy, or disabling it would hide the validation or state
that explains how to continue.

## Repository interpretation

Use existing button semantics. Distinguish disabled from pending and expose
validation or prerequisite information without relying on hover.
