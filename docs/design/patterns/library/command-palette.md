# Command Palette

`UI-PAT-018` · Primary guide: [Navigation](../navigation.md)

Posture: `RECOMMENDED`

## Use when

Many commands need fast discovery and the product already has a coherent
command model.

## Do not apply when

It would duplicate the existing Twenty command menu or hide primary actions.

## Repository interpretation

Extend existing Twenty command behavior. Define labels, keyboard shortcuts,
focus, unavailable commands, and recovery from failed actions.
