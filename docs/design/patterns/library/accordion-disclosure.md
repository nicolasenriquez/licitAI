# Accordion Disclosure

`UI-PAT-020` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `RECOMMENDED`

## Use when

Secondary detail benefits from an explicit, labeled disclosure control.

## Do not apply when

Hiding content would damage comparison, orientation, or task completion.

## Repository interpretation

Use semantic disclosure behavior and existing primitives. Choose single-open or
multiple-open behavior from the content relationship, not aesthetics.
