# Color Picker UX

`UI-PAT-017` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

The product has a real color-configuration feature with a defined value model.

## Do not apply when

Color is being added only as decoration or the chosen value cannot be exposed
accessibly and precisely.

## Repository interpretation

Reuse existing controls, labels, token mapping, keyboard behavior, and light/dark
contracts. Never use color as the only meaning carrier.
