# Swipe Actions

`UI-PAT-015` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `AVOID_BY_DEFAULT`

## Use when

A mobile workflow has a confirmed gesture model and every action has a visible
keyboard and pointer-equivalent path.

## Do not apply when

Swipe is the only way to discover or perform an important action.

## Repository interpretation

Do not add invisible mobile-only affordances to dense product surfaces without a
clear domain need and recovery model.
