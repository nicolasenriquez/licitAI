# Peak-End Rule

`UI-PAT-011` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `HEURISTIC`

## Use when

Reviewing the emotional and operational shape of a complete user journey.

## Do not apply when

It would justify artificial delight, decorative friction, or behavior that
conflicts with task clarity and accessibility.

## Repository interpretation

Use only as a design-review question. Product correctness and user control win.
