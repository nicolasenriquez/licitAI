# Landing Page Skeleton

`UI-PAT-055` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `OUT_OF_PRODUCT_SCOPE`

## Use when

Working on a confirmed marketing or website surface with its own design
register and package contract.

## Do not apply when

Working on Twenty product UI, CRM workflows, or Mercado Público.

## Repository interpretation

Route marketing work through `DESIGN.md` and the website package. Do not import
landing-page recipes into product surfaces.
