# Animation Timing

`UI-PAT-048` · Primary guide: [Motion](../motion.md)

Posture: `HEURISTIC`

## Use when

Choosing a purposeful transition after inspecting existing component behavior.

## Do not apply when

An external duration overrides repository motion tokens or makes the UI feel
slow, distracting, or inaccessible.

## Repository interpretation

Use existing motion behavior and test reduced motion. Timing is not a universal
performance or accessibility rule.
