# Stepper Wizard

`UI-PAT-029` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `CONTEXTUAL`

## Use when

Steps have real dependencies, distinct review boundaries, or a meaningful
sequence.

## Do not apply when

The pattern only splits a short form and makes review or navigation harder.

## Repository interpretation

Show progress, completed and invalid steps, back navigation, saved state, and
recovery. Preserve keyboard and URL behavior where applicable.
