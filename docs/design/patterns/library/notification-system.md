# Notification System

`UI-PAT-038` · Primary guide: [Feedback and Recovery](../feedback-and-recovery.md)

Posture: `RECOMMENDED`

## Use when

The product must communicate an event, status, or required follow-up.

## Do not apply when

The notification interrupts low-value work or makes durable information
available only temporarily.

## Repository interpretation

Match interruption to importance and reuse existing Twenty feedback primitives.
Give important events a durable surface and accessible status.
