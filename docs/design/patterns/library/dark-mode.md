# Dark Mode

`UI-PAT-070` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `REQUIRED_WHEN_AFFECTED`

## Use when

A visual change touches themes, semantic colors, tokens, or CSS variables.

## Do not apply when

Dark mode is implemented through ad hoc inversion or page-local color literals.

## Repository interpretation

Preserve existing light/dark theme seams, contrast, state meaning, and token
parity.
