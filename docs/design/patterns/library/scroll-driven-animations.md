# Scroll-Driven Animations

`UI-PAT-051` · Primary guide: [Motion](../motion.md)

Posture: `AVOID_BY_DEFAULT`

## Use when

A confirmed comprehension benefit justifies progressive enhancement and a
fully usable non-animated path exists.

## Do not apply when

Parallax or scroll effects distract from dense product content or fail reduced-
motion and performance checks.

## Repository interpretation

No current Mercado Público need. Never use it to communicate required data or
actions.
