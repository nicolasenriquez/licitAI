# Easing Curves

`UI-PAT-049` · Primary guide: [Motion](../motion.md)

Posture: `HEURISTIC`

## Use when

An existing transition needs a deliberate motion relationship.

## Do not apply when

Spring, bounce, or external easing recipes add ornamental motion without a user
orientation benefit.

## Repository interpretation

Follow existing Twenty motion language and reduced-motion behavior.
