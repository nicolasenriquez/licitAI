# Tabs System

`UI-PAT-045` · Primary guide: [Navigation](../navigation.md)

Posture: `RECOMMENDED`

## Use when

Views share a context and users need to switch among related panels.

## Do not apply when

Tabs hide unrelated workflows, make comparison difficult, or replace needed
route navigation.

## Repository interpretation

Use existing tabs with correct selected state, keyboard behavior, focus, and
responsive behavior.
