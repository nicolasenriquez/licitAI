# Dropdown Design

`UI-PAT-010` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `RECOMMENDED`

## Use when

The choice set and selection behavior fit an existing select or menu primitive.

## Do not apply when

The list is too large, the options need rich comparison, or a dropdown would
hide required context.

## Repository interpretation

Reuse Twenty primitives. Define focus, keyboard, collision, long-list, mobile,
loading, and empty behavior.
