# Z-Index Mastery

`UI-PAT-063` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `REQUIRED_WHEN_LAYERING`

## Use when

Overlays, menus, panels, or sticky surfaces need predictable stacking.

## Do not apply when

A large arbitrary z-index is being used to conceal an incorrect stacking
context or duplicate overlay implementation.

## Repository interpretation

Understand existing stacking contexts and reuse Twenty overlay primitives.
