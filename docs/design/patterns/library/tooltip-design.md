# Tooltip Design

`UI-PAT-014` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `CONTEXTUAL`

## Use when

A short supplementary explanation helps users understand a visible control.

## Do not apply when

The tooltip contains required instructions, critical actions, or information
that must remain visible.

## Repository interpretation

Trigger from focus as well as hover. Reuse Twenty tooltip behavior and preserve
touch, keyboard, collision, and dismissal behavior.
