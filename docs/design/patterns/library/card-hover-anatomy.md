# Card Hover Anatomy

`UI-PAT-050` · Primary guide: [Motion](../motion.md)

Posture: `AVOID_BY_DEFAULT`

## Use when

A secondary visual enhancement already fits an existing component and has a
focus, touch, and keyboard equivalent.

## Do not apply when

Hover reveals a critical action or ornamental lift harms dense scanning.

## Repository interpretation

Do not add card-hover polish to Mercado Público product surfaces by default.
Use visible, accessible actions.
