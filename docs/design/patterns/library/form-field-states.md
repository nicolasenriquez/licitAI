# Form Field States

`UI-PAT-026` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `REQUIRED`

## Use when

A field can be focused, invalid, disabled, pending, saved, or otherwise change
state during the task.

## Do not apply when

Decorative states are added without real behavior or without accessible labels.

## Repository interpretation

Make the states the user needs explicit. Associate errors with the field and do
not rely on color alone.
