# Toggle Anatomy

`UI-PAT-030` · Primary guide: [Forms and Editing](../forms-and-editing.md)

Posture: `RECOMMENDED`

## Use when

A setting has a clear binary state and changing it has an understandable effect.

## Do not apply when

The value is not binary or changing it needs a review flow better represented by
a form control.

## Repository interpretation

Use an existing toggle primitive. Expose label, state, pending, failure, and
keyboard behavior.
