# Design System Kit

`UI-PAT-057` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `REQUIRED_AS_CONTEXT`

## Use when

A feature needs shared visual primitives, states, or token decisions.

## Do not apply when

An external kit recipe conflicts with existing Twenty components or creates a
parallel design system.

## Repository interpretation

Use `twenty-ui`, its actual theme seams, and package contracts first. Extend a
primitive only when the existing one cannot meet the need.
