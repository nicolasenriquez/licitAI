# Focus States

`UI-PAT-046` · Primary guide: [Navigation](../navigation.md)

Posture: `REQUIRED`

## Use when

Any interactive control, overlay, table, form, or navigation surface changes
focus or keyboard order.

## Do not apply when

Focus styling is removed, hidden by decoration, or replaced with pointer-only
feedback.

## Repository interpretation

Preserve visible focus, logical order, focus entry, and focus return. Use the
repository's focus tokens and primitives.
