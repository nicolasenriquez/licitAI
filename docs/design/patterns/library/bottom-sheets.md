# Bottom Sheets

`UI-PAT-016` · Primary guide: [Overlays and Disclosure](../overlays-and-disclosure.md)

Posture: `CONTEXTUAL`

## Use when

A mobile overlay preserves context better than navigation and fits existing
Twenty primitives.

## Do not apply when

The sheet hides critical context, duplicates a route, or has no clear focus and
dismissal behavior.

## Repository interpretation

Treat it as a responsive overlay choice, not a new navigation model. Preserve
focus, state, and recovery.
