# Star Rating

`UI-PAT-013` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `AVOID_BY_DEFAULT`

## Use when

The domain explicitly requires a bounded ordinal rating and its meaning is
clear to all users.

## Do not apply when

Stars would imply a score, recommendation, or quality judgment the product does
not actually provide.

## Repository interpretation

There is no default Mercado Público rating model. Do not invent one for visual
polish.
