# Filter Chips

`UI-PAT-019` · Primary guide: [Search and Filter Discovery](../search-filter-discovery.md)

Posture: `REQUIRED_WHEN_FILTERING`

## Use when

Active filters materially change the visible result set and users need to
inspect or remove them.

## Do not apply when

There are no active constraints or the chip would hide a more understandable
control already present in the surface.

## Repository interpretation

Expose active value, removal, clear-all, result effect, keyboard access, and URL
state. Reset the Mercado Público cursor when filters change.
