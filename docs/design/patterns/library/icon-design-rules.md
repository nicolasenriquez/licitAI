# Icon Design Rules

`UI-PAT-065` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `RECOMMENDED`

## Use when

An icon improves recognition without replacing necessary text or accessible
meaning.

## Do not apply when

An unfamiliar icon is the only label or a new icon set creates visual drift.

## Repository interpretation

Reuse the existing icon library and primitives. Label icon-only controls and
preserve non-color meaning.
