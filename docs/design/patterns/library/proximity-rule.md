# Proximity Rule

`UI-PAT-060` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `RECOMMENDED`

## Use when

Spacing and grouping can make relationships and scanning order clearer.

## Do not apply when

Proximity creates ambiguous grouping or replaces required labels and semantics.

## Repository interpretation

Use repository spacing and hierarchy before adding decorative borders or cards.
