# Border Radius

`UI-PAT-069` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `REQUIRED_AS_REPO_TOKEN`

## Use when

A component or surface needs a rounded-corner value.

## Do not apply when

External radius values conflict with the component hierarchy or token contract.

## Repository interpretation

Use existing Twenty radius tokens. Do not copy “perfect card” recipes or literal
external pixel values.
