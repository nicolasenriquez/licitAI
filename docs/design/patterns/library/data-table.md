# Data Table

`UI-PAT-021` · Primary guide: [Data-Dense Surfaces](../data-dense-surfaces.md)

Posture: `REQUIRED_FOR_DENSE_RECORD_LISTS`

## Use when

Users need to scan and compare repeated structured records.

## Do not apply when

The content is primarily narrative, heterogeneous, or better represented by an
existing non-table Twenty surface.

## Repository interpretation

Use native semantic table structure, existing metadata-driven rendering, stable
headers, and complete loading/empty/error/selection/sorting/pagination states.
