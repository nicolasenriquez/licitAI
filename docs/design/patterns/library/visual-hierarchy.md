# Visual Hierarchy

`UI-PAT-062` · Primary guide: [Visual Foundations](../visual-foundations.md)

Posture: `REQUIRED`

## Use when

Users need to identify priority, relationships, and next actions quickly.

## Do not apply when

Decoration competes with content or hierarchy is based on unsupported metrics.

## Repository interpretation

Use task priority, truthful data, typography, spacing, and existing tokens. Keep
Mercado Público analytical and read-optimized.
