# Design Index

## Purpose

Route product and marketing design knowledge without loading unrelated material.

## Product UI

Use these documents for `twenty-front` and `twenty-ui` work:

- `design-system.md`
- `patterns/index.md`

Also read the closest package contracts before implementation.

## Mercado Público

For Mercado Público UI, additionally read:

- `patterns/mercado-publico-application.md`

Load only the pattern guides that match the task:

- tables or records: `patterns/data-dense-surfaces.md`
- search or filters: `patterns/search-filter-discovery.md`
- forms or editing: `patterns/forms-and-editing.md`
- loading, errors, or feedback: `patterns/feedback-and-recovery.md`
- modals, menus, drawers, or disclosure: `patterns/overlays-and-disclosure.md`
- navigation or pagination: `patterns/navigation.md`
- animation or transitions: `patterns/motion.md`

Do not load the complete pattern library by default.

## Marketing

For marketing surfaces, use the root `DESIGN.md`, the relevant website package
contract, and the marketing design register. Product pattern guides do not
apply by default.
