# Codex Index

## Purpose

Use this index to route repo-local Codex work inside `.codex/`.

## Surface Layout

| Path | Role |
| --- | --- |
| `.codex/commands/` | Repo-local command docs and workflows |
| `.codex/skills/` | Repo-local skill instructions and references |

## Routing Rule

- Stay in `.codex/` for repo-local Codex commands, skills, and workflow assets.
- Bounce back through root `index.md` when the task is really about the
  published plugin package, durable repository docs, OpenSpec change artifacts,
  or general package routing.
